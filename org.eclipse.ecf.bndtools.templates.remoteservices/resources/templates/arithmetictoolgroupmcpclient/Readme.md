#ArithmeticToolGroup MCP Test Client

This project provides a MCP ArithmeticToolGroup Test Client to test the ArithmeticToolGroup MCP Server.

##Launching MCP Tools Client/MCP Server

Before launching this MCP Tools Client a ArithmeticToolGroup Server project must be created from the ArithmeticToolGroup
MCP Server project template and the MCP server should be launched by opening the mcpserver.bndrun file and launching.  

Once the ArithmeticToolGroup MCP Server is running, to start the ArithmeticToolGroup MCP Client

1. Open the file [mcpclient.bndrun](mcpclient.bndrun) in the bndrun editor
2. Click on Resolve button on right and then Set Cache
3. Choose Run OSGi or Debug OSGi to launch the tools server
